# 🧠 AI Intelligence Hub
### Your Intelligent Data Workspace

AI Intelligence Hub is a data-driven dashboard designed to explore the Artificial Intelligence ecosystem. It brings AI news, job opportunities, startups, products, research papers, and GitHub repositories together in one interactive workspace.

The platform combines data visualization, dataset analytics, and an AI-powered assistant to help users explore AI industry information and discover insights.

---

## 🚀 Project Overview

AI Intelligence Hub helps users monitor and analyze different areas of the AI ecosystem through an interactive dashboard.

The application provides dataset summaries, interactive charts, searchable data tables, job market analytics, and an AI assistant capable of answering questions using the available datasets.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/shelkesagar819/AI_Intelligence_Hub.git
```

### 2. Navigate to the Project Directory

```bash
cd AI_Intelligence_Hub
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Configure Environment Variables

Create a `.env` file in the project root and configure the API key required for the AI Assistant.

Example:

```env
GROQ_API_KEY=your_api_key_here
```

Never upload your API keys or `.env` file to GitHub.

### 7. Run the Application

```bash
streamlit run app.py
```

The application will open in your browser.

## ⚠️ Data Limitations

- The current dataset is a limited snapshot, not a complete representation of the AI ecosystem.
- Startup records are currently limited.
- Research paper records are insufficient for meaningful scientific analysis.
- The research dataset currently includes a local test record that is not a verified scientific publication.
- AI Products data may include AI-related news or announcements and should not be considered a fully verified product catalogue.
- Job market analytics reflect the collected listings only.
- Salary information is not currently available in the AI Jobs dataset.
- AI news topic classification is based on keyword matching and may not perfectly represent article content.
- Some dashboard visualizations are illustrative/demo data rather than live ecosystem statistics.
